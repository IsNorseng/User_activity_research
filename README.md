# SQL-запросы на данных Stack Overflow

Учебная подборка запросов и заданий: объединения, агрегации, работа с датами, CTE и оконные функции.

Основной материал — [User activity research.ipynb](User%20activity%20research.ipynb). В репозитории также есть дублирующая копия `Untitled4.ipynb`. Для выполнения нужны PostgreSQL и база Stack Overflow из задания; база и эталонные результаты не приложены. Один запрос требует дополнительной проверки фильтра по году.
