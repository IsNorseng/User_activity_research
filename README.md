# Исследование активности пользователей Stack Overflow

Учебный SQL-кейс: собрать показатели активности пользователей Stack Overflow и ответить на серию аналитических вопросов.

## Что сделано

В репозитории — 20 последовательных задач с CTE, оконными функциями, агрегациями, датами и соединениями. Запросы рассматривают публикации, просмотры, голоса, теги и динамику активности по месяцам. Структура заданий показывает полный путь от простого среза до многошагового расчёта.

Основной материал: [notebook](notebook.sql) и дублирующая версия [notebook_1](notebook_1.sql). Файлы используют SQL-ячейки в Jupyter с подключением к PostgreSQL.

## Как запустить

1. Подготовьте PostgreSQL с таблицами Stack Overflow из задания.
2. Откройте notebook в Jupyter с SQL-магией и подключением к базе.
3. Выполняйте ячейки по порядку, проверяя названия схемы и диапазон дат.

Исходная база и сохранённые результаты в репозитории отсутствуют; точные версии окружения не зафиксированы.

## Ограничения

Это учебное исследование, а не мониторинг реального продукта. Один из запросов требует дополнительной проверки фильтра по году перед повторным использованием. Дублирующий файл оставлен как исходная версия материала; при дальнейшей работе его можно заменить на ссылку или убрать.

**Инструменты:** PostgreSQL, SQL, CTE, оконные функции, Jupyter.
